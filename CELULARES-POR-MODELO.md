# XEPCB Viewer V11 — celulares por modelo

Ruta: `public/biblioteca/celulares/<marca>/<modelo>/<tipo>/<archivo>`

Ejemplo: `public/biblioteca/celulares/iphone/iphone-13/boardviews/placa.pcb`

Puedes renombrar, eliminar o duplicar las carpetas de modelos desde tu PC. Usa los nombres que prefieras, por ejemplo `iphone-13-pro-max`. Dentro de cada modelo conserva `boardviews`, `overlays` y `esquematicos`. Solo aparecerán marcas, modelos y tipos que contengan archivos reconocidos después de publicar.

La navegación es Celulares → Marca → Modelo → Tipo.

Nota de seguridad: archivos de GitHub Pages siguen siendo públicos mediante URL directa.
